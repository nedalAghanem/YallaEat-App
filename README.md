# YallaEat App 🍔🚀

**YallaEat** هو تطبيق جوال مبتكر لإدارة طلبات المطاعم مع خدمة التوصيل السلسة. يوفر تجربة مستخدم متميزة وسهلة الاستخدام، مع واجهات جذابة وسرعة في تصفح القوائم وإتمام الطلبات.

## المميزات الرئيسية
- شاشة ترحيبية (Splash Screen) مع شعار المطعم  
- تسجيل الدخول والتسجيل بسهولة (Login / Register / Splash)  
- عرض قائمة المطاعم والوجبات بطريقة جذابة  
- إضافة الأصناف للسلة وتعديل الكميات  
- تأكيد الطلب وإشعارات الحالة  

## التقنيات المستخدمة
- Android Studio  
- Java  
- Trello لإدارة الفريق والمهام  
- GitHub لإدارة الإصدارات والتعاون
